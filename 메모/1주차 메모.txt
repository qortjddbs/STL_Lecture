fname -> naming convention (명명 규칙) - 사람들이 코드를 이해하기 쉽도록 한 약속

대표적인 naming convention
1. 클래스 및 구조체 (PascalCase)
클래스 및 구조체는 _ 대신 대문자로 단어를 구분하는 파스칼 케이스 방식을 많이 사용
ex) class PlayerCharacter / struct Vertor3D ...

2. 함수 및 매서드
방식 A (camelCase) : 첫 글자만 소문자, 그 뒤로는 대문자로 구분 (가장 흔함)
ex) void calculateDamage();
방식 B (PascalCase) : 1번과 동일 (구글 스타일가이드 및 언리얼 엔진)
ex) void CalculateDamage();
(참고) snake_case : _로 구분 (C++ 표준 라이브러리 - STL)
ex) std::vector::push_back()

3. 변수
snake_case 또는 camelCase
ex) int player_health;	(구글, STL 선호)
※ 주의 - 클래스의 멤버 변수는 구분하는 게 좋다
접미사 _ 사용 : int player_health_;	(구글 스타일)
접두사 m_ 사용 : int m_player_health;	(전통적인 C++ 스타일)

4. 상수 및 매크로
눈에 띄게 대문자로 작성
UPPER_SNAKE_CASE (모두 대문자, 단어 사이는 밑줄)
ex) const int MAX_PLAYER_COUNT = 100;
ex) #define PI 3.14159
(참고) 구글 스타일에서는 상수에 k붙이는 방식을 쓰기도 함 (const int kMaxPlayerCount = 100;)
