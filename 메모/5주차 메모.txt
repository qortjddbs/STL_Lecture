void (*a)() = f;        // a는 함수 f를 가리키는 포인터

a(); == f(); 

*a 를 무조건 소괄호로 감싸줘야 함! 안감싸면 void* 를 반환하는 함수라고 생각함!!

점프는 함수!
(*점프)();        // 이게 진짜 함수호출
// 점프()         // 이건 야매로 하는 호출!
"점프"라는 함수 주소에 가서 *로 값을 얻어오고 그걸 실행() 하라!!

    []() {
